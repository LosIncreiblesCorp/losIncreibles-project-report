# Capítulo III: Requirements Specification

## 3.1. User Stories.

En esta sección se definen los requisitos funcionales de InstAlert mediante épicas e historias de usuario. Cada historia expresa una necesidad y presenta criterios de aceptación con la estructura Dado-Cuando-Entonces. Se incluyen 40 historias de usuario y, por separado dentro de la misma tabla, 7 historias técnicas de API identificadas con el prefijo TS.
