# Capítulo III: Requirements Specification

## 3.1. User Stories.

En esta sección se definen los requisitos funcionales de InstAlert mediante épicas e historias de usuario. Cada historia expresa una necesidad y presenta criterios de aceptación con la estructura Dado-Cuando-Entonces. Se incluyen 50 historias de usuario (US) y, por separado, 29 historias técnicas de API (TS), cada grupo con su propia numeración.
